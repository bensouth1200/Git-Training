# Git cheat sheet

Five commands you will use in almost every session.

| Command | What it does |
|---|---|
| `git status` | Shows which files changed and what is staged for the next commit. |
| `git add` | Stages chosen changes so they are included in the next commit. |
| `git commit` | Saves a snapshot of the staged changes with a short message. |
| `git pull` | Downloads new commits from the remote and merges them into your current branch. |
| `git push` | Uploads your local commits to the remote so others can see them. |
